# ADR 0175: Signal Audit

Date: 2026-03-30

## Decision

Keep `signal-audit` in the public demo as a reduced, explanatory artifact.

## Boundary

I let this demo describe the workflow pattern, but I do not publish private
thresholds, account identifiers, runtime caches, or live execution paths.

## 中文摘要

公开演示只展示工作流形态，不发布私有阈值、账户标识、运行缓存或实盘路径。
