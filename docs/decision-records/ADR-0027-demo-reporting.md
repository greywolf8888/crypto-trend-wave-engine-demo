# ADR 0027: Demo Reporting

Date: 2025-02-18

## Decision

Keep `demo-reporting` in the public demo as a reduced, explanatory artifact.

## Boundary

The demo may describe the workflow pattern, but it must not publish private
thresholds, account identifiers, runtime caches, or live execution paths.

## 中文摘要

公开演示只展示工作流形态，不发布私有阈值、账户标识、运行缓存或实盘路径。
