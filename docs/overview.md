# Project Overview

Crypto Trend Wave Engine Demo is a reduced public version of a private
market-research workflow. The private system contains broader data adapters,
execution safeguards, and research automation. This demo keeps only publishable
offline examples.

## 中文摘要

本项目是私有市场研究流程的公开脱敏演示，仅保留可公开的离线样例、评分说明和测试边界。
