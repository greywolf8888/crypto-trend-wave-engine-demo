# Security Boundary

This public demo is offline and sanitized by design.

- No exchange API key is required.
- No account snapshot or live order history is included.
- No production trading endpoint is implemented.
- Demo data under `data_samples/` is synthetic.

## 中文说明

该公开演示仓库默认离线运行，不需要交易所密钥，不包含账户快照、
真实订单历史或生产交易入口。`data_samples/` 下的数据均为合成样本。
